Un prompt que convierte a cualquier modelo en un **redactor técnico** capaz de producir documentación profesional y bien estructurada. En lugar de improvisar un documento genérico, conduce una **entrevista estructurada** para entender el sistema, proceso o producto que hay que documentar antes de generar nada.

### Cómo se usa

1. Pega el prompt completo en tu modelo (Claude, GPT, etc.).
2. Responde a la entrevista: alcance, audiencia, nivel de detalle, formato de salida y secciones necesarias.
3. Aporta lo que tengas —notas, esquemas, flujos o capturas— para enriquecer el contenido.
4. Revisa la estructura propuesta y confirma o ajústala.
5. El modelo genera la documentación lista para usar.

### Qué genera

- **HTML estándar**: documento limpio, navegable y autocontenido para publicar o compartir.
- **HTML compatible con Microsoft Word**: se abre y edita directamente en Word conservando el formato, ideal para entregar a cliente o equipo.
- **Markdown**: ligero y versionable, perfecto para repositorios y wikis.

En todos los formatos reserva **espacios para capturas de pantalla** y **diagramas de flujo**, con marcadores claros de dónde colocarlos.

### Para qué casos sirve

Manuales de usuario, guías técnicas, documentación funcional de aplicaciones, procedimientos internos, guías de onboarding o cualquier documento que deba quedar claro, completo y profesional sin partir de una plantilla en blanco.
